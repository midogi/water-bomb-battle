# 개발 체크리스트

## 팀에서 먼저 결정

- [ ] 역할별 담당자
- [ ] 맵 15×13, 타일 40px, 틱 50ms, 최대 4인 확정
- [ ] 플레이어의 틱당 이동 속도
- [ ] 갇힌 플레이어 접촉 시 즉시 탈락 여부
- [ ] 아이템 종류·효과·드롭 확률 (`ItemType`은 합의 후 추가)
- [ ] 방장 퇴장 시 다음 방장 선정
- [ ] 닉네임·방 제목의 구분자 처리, 에러 코드 목록
- [ ] 직접 제작할 캐릭터·맵 이미지 방식

## 1차 통합

- [x] 메시지 타입, UTF-8 길이 프레이밍, 상수 초안
- [x] 서버와 클라이언트 접속, ID 배정, 로그인
- [ ] 1서버·4클라이언트 접속을 팀원 PC에서도 확인
- [ ] UserSession, Room, RoomManager, Broadcaster
- [ ] 방 생성·입장·퇴장, 준비·시작
- [ ] 같은 방 채팅·이모티콘

## 2차 통합

- [ ] 방별 GameLoop와 ConcurrentLinkedQueue 입력 처리
- [ ] 네모 캐릭터 이동·충돌 및 STATE 공유
- [ ] Swing 로비·게임 화면, 키 입력, 수신 상태 표시
- [ ] 폭탄·폭발·상자·아이템
- [ ] 피격·탈락·동시 판정·접속 종료·승패 처리
- [ ] 애니메이션·사운드·4인 시연

## 변경 기록

- 2026-11-09: `server/game` 독립 모듈과 18개 게임 로직 테스트 추가. 네트워크·GUI 통합과 아이템은 대기 중이며 기존 통합 체크 항목은 완료로 처리하지 않음.

- 2026-11-06: 개발 규약 초안을 바탕으로 저장소와 접속 확인용 코드를 구성함. 역할과 미정 수치는 확정하지 않음.
